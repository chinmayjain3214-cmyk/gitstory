What's in a story

Seven chapters, all drawn from the repository's own commits. Every chart animates in as you scroll.

  1. The headline numbers

    First and latest commit, total commits, contributors, lines added and removed, and the project's age, counting up as the page opens.

  2. Animated timeline

    Commits per week, drawn left to right. Hover any week to see its busiest moment.

  3. Contributors

    Everyone who shaped the project, ranked, with their lines changed, active dates and an activity sparkline.

  4. When the code gets written

    A day-by-hour heatmap and a verdict: night owls, early birds, 9-to-5ers or weekend warriors.

  5. File churn

    The fifteen files that change the most, and the languages doing the heavy lifting.

  6. Commit messages

    Average length, favourite words, how often feat: and fix: show up, and the longest and shortest messages.

  7. Fun facts

    The biggest single commit, the longest streak, the longest silence and the busiest day ever.

How it works

  1. 1

    Paste a link

    Any GitHub repository link works, even one to a file or a branch. owner/repo is fine too.

  2. 2

    gitstory reads the history

    It clones the default branch with git, reads every commit with git log, and works out the numbers.

  3. 3

    Read it, keep it, share it

    The story opens right here. Download it as one HTML file that works offline, with no account needed.

🔒 Everything runs on this computer. The copy of the repository is deleted as soon as it has been read, and nothing is uploaded anywhere.
